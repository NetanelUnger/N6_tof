# Fast UART boot — 2026-10-27

Branch: feature/n6-xip-ota-usb. Hardware programmed; boot and HIL100 passed after opening radio SB31/SB34. See final acceptance below.

The shared banner previously printed 50 rows, waited 5000 ms, and erased the
terminal both before and after rendering. FSBL, Secure and NonSecure each
called it, creating 15000 ms of explicit display-only delay even when the
NonSecure output was disabled. The replacement appends seven logo rows and
three short stage/version/action lines. It has no delay callback or ANSI
cursor/screen controls. UART transmission still takes wire time at 115200 baud;
this is not a claim of instantaneous startup or measured hardware latency.

FSBL reports NOR mapping and image authentication; Secure reports protected
update-service initialization and retains its handover diagnostics. NonSecure
prints peripheral completion and the ThreadX handoff using the existing bounded
polling writer before the scheduler starts. These startup messages remain
visible with N6_DEBUG_OUTPUT_ENABLED=0; ordinary runtime debug stays disabled.
The separate interactive USB CLI and explicitly requested map display retain
their existing terminal controls.

No authentication, metadata, rollback, watchdog, trial-confirmation window,
peripheral settling delay, clock configuration or memory mapping was changed.
All main.c changes except the additional Secure progress line are within USER
CODE blocks; that line is adjacent to existing manually maintained Secure
initialization and should be preserved during regeneration. No Generate Code
is required for this C-only change.
